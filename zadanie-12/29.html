Задание 12 ЕГЭ по информатике: задача 29

Исполнитель Редактор · добавлено 2026-10-19

Исполнитель Редактор получает на вход строку цифр и преобразовывает её. Команда заменить(v, w) заменяет в строке первое слева вхождение цепочки v на цепочку w; команда нашлось(v) проверяет, встречается ли цепочка v в строке.

Какая строка получится в результате применения приведённой ниже программы к строке, состоящей из 162 идущих подряд цифр 2?

НАЧАЛО
ПОКА нашлось(222) ИЛИ нашлось(55)
  ЕСЛИ нашлось(222)
    ТО заменить(222, 55)
    ИНАЧЕ заменить(55, 2)
  КОНЕЦ ЕСЛИ
КОНЕЦ ПОКА
КОНЕЦ

Разбор

Показать решение
  1. Редактор — это ровно str.replace(..., 1): замена только первого вхождения. Без третьего аргумента Python заменит все вхождения сразу, и ответ может разойтись.
  2. Каждая замена укорачивает строку (3→2 и 2→1 символов), поэтому цикл гарантированно закончится.
  3. Моделируем на строке из 162 цифр 2 и печатаем результат.
  4. Ответ: 22.

Код решения на Python

def run(s):
    while '222' in s or '55' in s:
        if '222' in s:
            s = s.replace('222', '55', 1)
        else:
            s = s.replace('55', '2', 1)
    return s


print(run('2' * 162))

Программа печатает ответ, её можно вставить в любую IDE на экзамене как есть.
