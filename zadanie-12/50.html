Задание 12 ЕГЭ по информатике: задача 50

Исполнитель Редактор · добавлено 2026-10-29

Исполнитель Редактор получает на вход строку цифр и преобразовывает её. Команда заменить(v, w) заменяет в строке первое слева вхождение цепочки v на цепочку w; команда нашлось(v) проверяет, встречается ли цепочка v в строке.

На вход приведённой ниже программе поступает строка, состоящая из n цифр 8 (10 ≤ n ≤ 100). Определите наибольшее значение n, при котором сумма цифр в строке, получившейся в результате выполнения программы, максимальна.

ПОКА нашлось(88) ИЛИ нашлось(4444)
  ЕСЛИ нашлось(88)
    ТО заменить(88, 4)
    ИНАЧЕ заменить(4444, 888)
  КОНЕЦ ЕСЛИ
КОНЕЦ ПОКА
КОНЕЦ

Разбор

Показать решение
  1. Перебираем все n из диапазона и для каждого моделируем программу через str.replace(..., 1) — это и есть «первое вхождение».
  2. Ключ сортировки — пара (сумма цифр, n): при равной максимальной сумме выиграет большее n, как и требует условие.
  3. Искать закономерность руками можно (результат периодичен по n), но на экзамене перебор быстрее и надёжнее.
  4. Ответ: 95.

Код решения на Python

def run(s):
    while '88' in s or '4444' in s:
        if '88' in s:
            s = s.replace('88', '4', 1)
        else:
            s = s.replace('4444', '888', 1)
    return s


best = max(range(10, 101), key=lambda n: (sum(map(int, run('8' * n))), n))
print(best)
