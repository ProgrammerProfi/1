Задание 8 ЕГЭ по информатике: задача 26

Комбинаторика: перебор слов · добавлено 2026-10-19

Петя составляет 5-буквенные слова из букв В, Д, И, П, Р, С, У. Каждая буква может входить в слово любое количество раз или не входить совсем. Словом считается любая допустимая последовательность букв, не обязательно осмысленная.

Сколько существует таких слов, которые содержат ровно одну букву Д и не заканчиваются буквой П?

Разбор

Показать решение
  1. Всего слов 75 = 16807, перебрать их все — мгновенно. Поэтому решаем перебором через itertools.product и просто проверяем условие.
  2. Ровно одно вхождение проверяем через w.count(...) == 1, последнюю букву — через w[-1].
  3. Формулой тоже можно, но там легко пропустить случай. Перебор не ошибается.
  4. Ответ: 5616.

Код решения на Python

from itertools import product

cnt = 0
for w in product('ВДИПРСУ', repeat=5):
    if w.count('Д') == 1 and w[-1] != 'П':
        cnt += 1
print(cnt)
