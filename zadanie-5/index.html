Задание 5 ЕГЭ по информатике

Анализ алгоритма: двоичная запись

Что проверяет задание

Дан алгоритм, который берёт число N, строит его двоичную запись, что-то дописывает или меняет и получает новое число R. Нужно найти N или R с каким-то свойством: минимальное, максимальное, ближайшее к границе.

Как решать

Моделированием. Переписываешь алгоритм в функцию и перебираешь N. Руками считать можно, но одна ошибка в разряде стоит балла.

def R(n):
    b = bin(n)[2:]          # двоичная запись без '0b'
    # ... обработка по условию ...
    return int(b, 2)

print(min(R(n) for n in range(1, 10000) if R(n) > 100))

Где ошибаются

  • Останавливаются на первом подходящем N, когда спрашивают минимальное R. R растёт не монотонно, нужен минимум по всем N.
  • Путают «больше» и «не меньше» в условии.
  • Забывают ограничение на N из условия (например, N ≥ 4) и перебирают с единицы.
  • Используют bin(n) без среза и получают в строке лишние символы 0b.
