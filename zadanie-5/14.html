Задание 5 ЕГЭ по информатике: задача 14

Анализ алгоритма: двоичная запись · добавлено 2026-10-19

На вход алгоритма подаётся натуральное число N (N ≥ 4). Алгоритм строит по нему новое число R следующим образом.

  1. Строится двоичная запись числа N.
  2. Далее эта запись обрабатывается по правилу: если N чётное, то к двоичной записи справа дописываются цифры 00, а если нечётное — цифры 01.
  3. Полученная таким образом запись является двоичной записью искомого числа R.

Укажите минимальное число R, большее 317, которое может быть получено с помощью этого алгоритма. В ответе запишите это число в десятичной системе счисления.

Разбор

Показать решение
  1. Задачи №5 решаются прямым моделированием. Пишем функцию R(n), которая делает ровно то, что написано в условии, и перебираем N. Руками это делать долго и легко ошибиться в одном разряде.
  2. Двоичную запись удобно держать строкой: bin(n)[2:] даёт её без префикса 0b, дописывание справа — это конкатенация, а обратно в число переводит int(b, 2).
  3. Здесь важно перебрать все N, а не остановиться на первом подходящем: R растёт с N не монотонно, поэтому берём минимум из всех R(N) > 317.
  4. Ответ: 320.

Код решения на Python

def R(n):
    b = bin(n)[2:]
    b += '00' if n % 2 == 0 else '01'
    return int(b, 2)


print(min(R(n) for n in range(4, 10000) if R(n) > 317))
