Задание 23 ЕГЭ по информатике

Количество программ исполнителя

Идея

f(x, y) — количество программ, переводящих x в y. Если все команды увеличивают число:

  • x > y — 0 программ;
  • x = y — 1 программа (пустая);
  • иначе — сумма f(команда(x), y) по всем командам.

«Траектория содержит c» — это произведение f(s, c) · f(c, t). «Не содержит d» — считаем, что из d путей нет.

from functools import lru_cache

@lru_cache(None)
def f(x, y):
    if x > y or x == 13:
        return 0
    if x == y:
        return 1
    return f(x + 1, y) + f(x * 2, y)

print(f(2, 10) * f(10, 30))

Где ошибаются

  • Проверяют запрещённое число после проверки x == y, и запрещённый конец пути засчитывается.
  • С командой «возвести в квадрат» стартуют с 1 — получается бесконечная рекурсия.
  • Если есть команда, уменьшающая число, условие x > y уже неверно, нужен другой подход.
