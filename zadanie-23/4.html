Задание 23 ЕГЭ по информатике: задача 4

Количество программ исполнителя · добавлено 2026-10-19

Исполнитель преобразует число на экране. У исполнителя есть 3 команды:

  • A. Прибавить 1
  • B. Прибавить 4
  • C. Умножить на 3

Программа для исполнителя — это последовательность команд. Траектория вычислений программы — это последовательность результатов выполнения всех команд программы.

Сколько существует программ, для которых при исходном числе 4 результатом является число 25, и при этом траектория вычислений содержит число 16 и не содержит числа 14?

Разбор

Показать решение
  1. f(x, y) — число программ, переводящих x в y. Все команды только увеличивают число, поэтому если x > y, путей нет, а x = y даёт ровно одну (пустую) программу.
  2. «Траектория содержит 16» — значит, путь распадается на два независимых куска: 4 → 16 и 16 → 25. Число программ — произведение.
  3. «Не содержит 14» — просто считаем, что из 14 путей нет: x == 14 возвращает 0.
  4. Считаем: f(4, 16) · f(16, 25) = 140.
  5. Ответ: 140.

Код решения на Python

from functools import lru_cache


@lru_cache(None)
def f(x, y):
    if x > y or x == 14:
        return 0
    if x == y:
        return 1
    return f(x + 1, y) + f(x + 4, y) + f(x * 3, y)


print(f(4, 16) * f(16, 25))
