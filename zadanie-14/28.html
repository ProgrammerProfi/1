Задание 14 ЕГЭ по информатике: задача 28

Системы счисления · добавлено 2026-10-19

Значение арифметического выражения 25141 + 25117 − 2205 записали в системе счисления с основанием 2. Сколько цифр 0 содержится в этой записи?

Разбор

Показать решение
  1. Python работает с длинными целыми без ограничений, так что считаем значение выражения напрямую.
  2. Дальше обычный перевод в систему с основанием 2: берём остаток от деления на 2 (очередная цифра справа) и делим нацело.
  3. Аналитический путь (через то, как выглядит в записи степень основания минус число) полезен, когда основание выражения — степень q. Но он требует аккуратности, а код даёт ответ сразу.
  4. Ответ: 333.

Код решения на Python

v = 25**141 + 25**117 - 2205
cnt = 0
while v:
    cnt += v % 2 == 0
    v //= 2
print(cnt)
