Задание 2 ЕГЭ по информатике

Таблицы истинности

Что проверяет задание

Дана логическая функция F от переменных x, y, z, w и фрагмент её таблицы истинности: три разные строки, часть клеток пустая, а подписи столбцов не указаны. Нужно понять, какой переменной соответствует каждый столбец.

Как решать

Перебором. Пустые клетки заполняем всеми способами через product, буквы расставляем по столбцам через permutations и оставляем расстановку, при которой F на всех строках равна значению из таблицы.

from itertools import product, permutations

def F(x, y, z, w):
    return (w <= x) <= (z <= y)     # F = (w → x) → (z → y)

ans = set()
for a, b, c, d, e, f, g in product([0, 1], repeat=7):   # буква на каждую пустую клетку
    t = [(a, b, c, 1), (0, d, e, f), (1, 1, g, 0)]
    if len(set(t)) < len(t):                          # строки обязаны быть разными
        continue
    for p in permutations('xyzw'):
        if all(F(**dict(zip(p, r))) == 0 for r in t):   # в столбце F стоят нули
            ans.add(''.join(p))
print(*ans)

Операции в Python

  • Конъюнкция ∧ — and, дизъюнкция ∨ — or, отрицание ¬ — not.
  • Импликация a → b — a <= b или (not a) or b.
  • Эквивалентность a ≡ b — a == b.

Где ошибаются

  • Не проверяют, что строки разные, и получают несколько ответов.
  • Пишут импликации без скобок. a <= b <= c в Python — это цепочка сравнений, а не (a → b) → c. Каждую операцию берите в скобки.
  • Сравнивают F с 1, когда в таблице столбец F заполнен нулями.
  • Записывают в ответ порядок переменных, а не порядок столбцов.
