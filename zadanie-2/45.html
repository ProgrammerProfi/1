Задание 2 ЕГЭ по информатике: задача 45

Таблицы истинности · добавлено 2026-10-24

Миша заполнял таблицу истинности логической функции F

F = ((w ∧ (x → y)) ≡ y) → z

но успел заполнить лишь фрагмент из трёх различных её строк, даже не указав, какому столбцу таблицы соответствует каждая из переменных x, y, z, w. Пустые клетки — значения, которые Миша не вписал.

Перем. 1Перем. 2Перем. 3Перем. 4F
010
100
100

Определите, какому столбцу таблицы соответствует каждая из переменных x, y, z, w.

В ответе напишите буквы x, y, z, w в том порядке, в котором идут соответствующие им столбцы (сначала буква, соответствующая первому столбцу; затем буква, соответствующая второму столбцу, и т. д.). Буквы в ответе пишите подряд, никаких разделителей между буквами ставить не нужно.

Разбор

Показать решение
  1. Импликацию a → b в Python удобно писать как a <= b: на нулях и единицах это ровно та же таблица (ложно только 1 → 0). Эквивалентность a ≡ b — это a == b. Отрицание — not. Каждую операцию берём в скобки, чтобы не думать о приоритетах.
  2. Функция F = 0 на 5 наборах из 16 (порядок x y z w): 0000, 0101, 1000, 1001, 1101. Каждая строка фрагмента после заполнения пропусков обязана стать одним из этих наборов.
  3. В таблице 6 пустых клеток, значит вариантов их заполнения 26 = 64. Для каждого варианта пробуем все 24 расстановки букв по столбцам — всего 1536 проверок, это мгновенно.
  4. Важное условие — строки разные. Варианты заполнения, где две строки совпали, отбрасываем, иначе можно получить лишний ответ.
  5. Подходит только одна расстановка: zxwy. Заполненные строки (значения по столбцам слева направо): 0011 — это x=0, y=1, z=0, w=1; 0100 — это x=1, y=0, z=0, w=0; 0110 — это x=1, y=0, z=0, w=1. На каждом из этих наборов F = 0.
  6. Ответ: zxwy.

Код решения на Python

from itertools import product, permutations


def F(x, y, z, w):
    return (((w and (x <= y)) == y) <= z)


ans = set()
for a, b, c, d, e, f in product([0, 1], repeat=6):
    t = [(0, a, b, 1), (c, 1, d, 0), (e, 1, f, 0)]
    if len(set(t)) < len(t):  # строки фрагмента должны быть разными
        continue
    for p in permutations('xyzw'):
        if all(F(**dict(zip(p, r))) == 0 for r in t):
            ans.add(''.join(p))
print(*ans)
