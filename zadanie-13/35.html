Задание 13 ЕГЭ по информатике: задача 35

IP-адреса и маски · добавлено 2026-10-19

Сеть задана IP-адресом и маской. Адрес сети получается поразрядной конъюнкцией IP-адреса любого узла этой сети и маски.

Сеть задана адресом 207.177.176.0 и маской 255.255.248.0. Сколько в этой сети IP-адресов, для которых количество единиц в двоичной записи IP-адреса не кратно 3? В ответе укажите только число.

Разбор

Показать решение
  1. Маска 255.255.248.0 — это /21, в сети 211 = 2048 адресов. Перебрать их все — мгновенно.
  2. Итерация по ip_network выдаёт все адреса сети, включая адрес сети и широковещательный — условие говорит «IP-адресов в сети», поэтому их учитываем.
  3. int(a) переводит адрес в 32-битное число, дальше считаем единицы через bin(...).count('1').
  4. Ответ: 1365.

Код решения на Python

from ipaddress import ip_network

cnt = 0
for a in ip_network('207.177.176.0/255.255.248.0'):
    if bin(int(a)).count('1') % 3 != 0:
        cnt += 1
print(cnt)
