Задание 25 ЕГЭ по информатике

Маски чисел и делимость

Маски

«?» — ровно одна цифра, «*» — любая последовательность цифр, в том числе пустая. Это ровно синтаксис fnmatch из стандартной библиотеки.

Как решать

Перебирать все числа до 1010 нельзя. Зато можно перебирать только кратные делителю: шагов становится в D раз меньше.

from fnmatch import fnmatch
for x in range(2023, 10**10 + 1, 2023):
    if fnmatch(str(x), '1?2139*4'):
        print(x, x // 2023)

Если делитель маленький, а маска почти вся из цифр, быстрее перебирать подстановки в маску: каждый «?» — 10 вариантов, «*» — строки длины 0, 1, 2…

Где ошибаются

  • Забывают, что «*» может быть пустой.
  • Начинают перебор с 0 и получают в ответе ноль.
  • Пишут свою проверку маски и ошибаются на краевых случаях.
