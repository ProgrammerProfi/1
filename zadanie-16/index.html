Рекурсивные функции

Рекурсия в Python

Определение функции переписывается в код один в один. Дальше возможны две проблемы.

  • Глубина. Стандартный лимит рекурсии — около 1000. Если n порядка 2000 и больше, поднимаем лимит: sys.setrecursionlimit(10000). Либо считаем снизу вверх циклом.
  • Повторные вычисления. Если внутри два рекурсивных вызова, без кэша время растёт экспоненциально. Помогает @lru_cache(None).
import sys
from functools import lru_cache
sys.setrecursionlimit(10000)

@lru_cache(None)
def F(n):
    if n == 1:
        return 1
    return n * F(n - 1)

print(F(2024) // F(2022))

Где ошибаются

  • Используют / вместо // на огромных числах и получают OverflowError.
  • Меняют порядок проверок и база не срабатывает.
