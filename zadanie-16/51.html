Задание 16 ЕГЭ по информатике: задача 51

Рекурсивные функции · добавлено 2026-10-30

Алгоритм вычисления значения функции F(n), где n — натуральное число, задан следующими соотношениями:

F(n) = 3 при n ≤ 2;
F(n) = F(n − 1) + 2·n, если n > 2 и n чётно;
F(n) = 3·F(n − 2) − n, если n > 2 и n нечётно.

Чему равно значение функции F(39)?

Разбор

Показать решение
  1. Переписываем определение в функцию один в один. Порядок проверок важен: сначала база n ≤ 2, потом чётность.
  2. Глубина рекурсии маленькая (до 39), и каждый вызов порождает только один рекурсивный, так что кэш не нужен.
  3. Частая ошибка — перепутать условия «чётно/нечётно» местами или забыть, что база проверяется раньше.
  4. Ответ: 1162261488.

Код решения на Python

def F(n):
    if n <= 2:
        return 3
    if n % 2 == 0:
        return F(n - 1) + 2 * n
    return 3 * F(n - 2) - n


print(F(39))
