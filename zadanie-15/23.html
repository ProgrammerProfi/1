Задание 15 ЕГЭ по информатике: задача 23

Логические выражения: ДЕЛ и отрезки · добавлено 2026-10-19

Обозначим через ДЕЛ(n, m) утверждение «натуральное число n делится без остатка на натуральное число m».

Для какого наименьшего натурального числа A формула

ДЕЛ(x, A) → (¬ДЕЛ(x, 13) → ДЕЛ(x, 14))

тождественно истинна (то есть принимает значение 1 при любом натуральном значении переменной x)?

Разбор

Показать решение
  1. Решаем перебором: для каждого кандидата A проверяем формулу на большом отрезке x. Если нашёлся x, где формула ложна, A не подходит.
  2. Импликацию p → q в Python пишем как (not p) or q, а ДЕЛ(x, m) — как x % m == 0.
  3. Формула равносильна ¬ДЕЛ(x, A) ∨ ДЕЛ(x, 13) ∨ ДЕЛ(x, 14). Она должна быть истинна для каждого x, в том числе для x = A. Значит, A само должно делиться на 13 или на 14; тогда и все его кратные тоже. Наименьшее такое A — 13.
  4. Почему хватает x до 5000: все делимости здесь периодичны с периодом НОК(A, 13, 14), и для подходящих A этот период укладывается в диапазон. Если сомневаешься, увеличь границу и убедись, что ответ не поменялся.
  5. Ответ: 13.

Код решения на Python

def f(x, A):
    return (x % A != 0) or (x % 13 == 0) or (x % 14 == 0)


print(min(A for A in range(1, 2000) if all(f(x, A) for x in range(1, 5000))))
