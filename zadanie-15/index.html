Задание 15 ЕГЭ по информатике

Логические выражения: ДЕЛ и отрезки

Подход

Импликация A → B равна ¬A ∨ B. После этого почти любую формулу можно проверить перебором: для кандидата A проверяем формулу на всех x из большого диапазона.

def f(x, A):
    return (x % A == 0) or not (x % 6 == 0 and x % 9 == 0)

print(max(A for A in range(1, 1000)
          if all(f(x, A) for x in range(1, 1000))))

Для отрезков на прямой перебор по целым x не годится: границы могут быть важны. Проверяй сами концы отрезков и середины между ними — истинность формулы меняется только в этих точках.

Где ошибаются

  • Пишут импликацию как a <= b и путают порядок операндов.
  • Берут слишком маленький диапазон x, и подходящими оказываются лишние A.
  • Путают «наибольшее» и «наименьшее».
